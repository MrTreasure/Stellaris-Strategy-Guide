# 15｜硕果协作·星种花园：让缇扬奇替你把种子送往银河

> 版本：4.4.6 Pegasus。硕果协作只允许植物/真菌物种，并要求亲外、和平或蜂巢思维；太空生物会传播种荚，帝国可以用星种花园和播种轰炸推动特殊殖民。[起源数据](https://qunxing.huijiwiki.com/wiki/Data%3ACivics/origin_fruitful.json)

## 玩法定位

这是一条事件驱动的和平扩张路线。你不完全控制种子落到哪里，因此不能像普通殖民船一样制定精确时间表；正确打法是先维持一套正常经济，把散播成功视为额外殖民窗口，再用田园绽放把成熟殖民地逐步培育成盖亚世界。

## 建国模板：远星花冠

- 物种：植物类，使用花冠/藤蔓肖像。
- 起源：**硕果协作**。
- 政体：民主制。
- 思潮：极端亲外主义＋和平主义。
- 理念：**田园绽放**＋**环保主义者**。
- 特质：光养、适应性、传统；负面选桀骜、定居。

## 核心优势、成型拐点与飞升原理

### 把随机播种变成额外殖民入口，而不是拿它替代正常经济

普通帝国的远方殖民必须先铺星系、支付影响力并保持连续边界；硕果协作可以借太空生物传播种荚，偶尔在常规扩张范围之外获得星球和战略支点。田园绽放再把值得长期经营的世界逐步提高质量。其优势是**增加殖民机会的上限并改善成熟星球质量**，而不是保证前十年更快；所以构筑必须拥有一套不依赖随机事件也能运转的前三球经济。

机制链是：`正常资源球/工业球托底 → 星种花园利用缇扬奇路线 → 筛选安全高价值种荚 → 额外殖民地或战略跳板 → 亲外外交保护飞地与多物种流动 → 田园绽放提升优质核心 → 更高人口承载和岗位效率`。真正的快速成型来自“只兑现好机会”，不是激活所有种子。

### 传统、飞升与机会成本

- 扩张树适合已有正常殖民目标且种荚位置良好的地图；若十年内没有可兑现种子，繁荣先强化现有三球，不能为主题空等。
- 每颗远方世界同时增加殖民地规模、守备成本与外交风险。激活前用未来资源和战略位置计算回本；它不能回本，就算免费送到也会拖慢传统。
- 凝聚力的快慢由行政月产和帝国规模共同决定。星种/外交事件是块状加速，只应用来提前关键传统，不能据此关闭稳定统一岗位。
- 飞升选择应保留植物生态与田园绽放协同；尤其不要选择会令该理念失效的合成路线。科技前置或花园经济尚未成熟时，先跑殖民与升级循环比抢槽位重要。

### 强势窗口与成型判断

- **最早窗口：2215—2230。**正常两颗殖民地已供血，同时出现一颗安全且有价值的星种世界，相当于免费打开额外扩张轴。
- **稳健窗口：2240—2260。**核心田园绽放设施可持续升级，远方世界由外交/防御网络保护，多物种岗位开始提高星球利用率。

成型指标：①不计算星种事件，首都＋两颗常规殖民地仍能资源自洽；②至少一个种荚目标通过安全、宜居、距离和资源四项筛选；③激活后凝聚力仍在 `32—45/月` 且传统时间没有失控；④田园设施升级不靠反复卖合金；⑤远方世界有舰队/盟友保护，并承担明确资源或跳板职责。

**不要无脑早飞升：**遇到稀有安全种荚时先完成殖民，田园升级即将兑现时先保资源，外交窗口出现时先签开边/防御关系。反过来，种荚位置差、边境危险或前三球未自洽时，就按普通繁荣/扩张经济推进；为了“快速飞升”激活多个孤立空球，只会提高成本并延迟真正成型。

## 传统与飞升点法

1. **第一树按地图选扩张或繁荣。**十年内有两颗正常宜居球或一颗高价值安全种荚，就选扩张，先拿殖民上线、人口价值和规模控制效果；种荚不明、殖民目标差，则选繁荣，先降建设维护并提高现有岗位。
2. **2220—2230 闭门。**星种事件不能当稳定凝聚力预算；闭门依赖行政岗位和派系保底。每激活一颗飞地都重新检查传统完成时间，若增加超过可接受范围，先让旧球回本。
3. **前两槽用通用天赋，第 3 槽基因重塑。**硕果协作没有提前入口；先完成扩张、繁荣、外交三棵普通树并拿两枚通用天赋，第 3 槽选择**基因重塑（Biomorphosis）**。基因剪裁在局势中段前补完即可；明确排除会使田园绽放失效的合成路线。
4. **专属树与后续树。**飞升树先点人口成长、宜居/改造和覆盖多岗位的生产效果，窄领袖或军队效果后补。第一树扩张则第二树繁荣，第一树繁荣且星种连续兑现则第二树扩张；飞地依赖外交保护时第三棵外交，战争压力高则改至高。
5. **改线条件。**十年无好种荚：按普通繁荣经济，不继续为播种加码；出现遥远优质球但守不住：先外交/舰队；田园升级导致资源赤字：暂停升级而非砍统一；已选生态理念后不要因合成科技先出现就改飞升方向。

## 2200—2210：正常殖民是主食，星种是惊喜

1. 开局建星种花园并观察附近缇扬奇路线，但不要停掉正常科研与殖民准备。
2. 第一艘殖民船仍然投向能稳定经营的资源球；等待随机种荚不能替代前十年扩张。
3. 第一殖民地做能源/矿物，第二颗做工业。田园绽放设施需要长期投入，基础经济稳定后再逐级升级。
4. 对落入远方或危险区域的种荚先看边界、宜居性和守备成本，不是每颗都必须立刻激活。
5. 外交优先开边、迁徙和防御合作，避免太空生物路线与邻国边境把种子循环截断。

星种世界不能打乱前三球基础分工。它是额外机会：好球加速扩张，烂球则暂缓激活或低投入经营，不为了主题强行把经济拉成长蛇。

## 前期凝聚力方案

### 凝聚力来源顺序

1. 首都行政岗位是随机播种尚未兑现前的保底。
2. 传统特质、民主议程和亲外/和平派系在政治结构成形后提供持续补充。
3. 田园绽放、星种发现和外交事件的奖励只算阶段加速，不作为固定月产。
4. 多物种贸易经济在中期可以测试思想市场，但前期没有专职商人时，直接行政岗位更便宜；不要为了旧版贸易飞升流延后扩张树。

- 2205：可支配凝聚力 **22—30/月**，环保与亲外主题不能代替行政岗位。
- 2210：达到 **32—45/月**；第一树优先扩张，地图封闭或种荚很少时改繁荣。
- 第一槽位目标 **2220—2230**。随机获得的新殖民窗口会推高帝国规模，因此每次激活前都重看传统价格。
- 田园绽放路线不适合合成飞升：选择合成进化会使该理念失效。
- 中期多物种与盖亚星成形后，再把统一岗位部分转向科研与外交。

## 殖民判断

收到种荚机会时依次检查：能否守住、宜居性、离现有边界距离、资源分工、是否会让凝聚力低于目标。满足至少四项再激活；否则让它等待，不为主题强行养一颗孤立空球。

## 常见翻车点

- 全程等缇扬奇播种，十年没有正常殖民地。
- 每个种荚都激活，边境变成无法防守的飞地。
- 过早升级盖亚播种器，消费品与能量被长期项目抽干。
- 选择合成飞升后才发现田园绽放失效。
