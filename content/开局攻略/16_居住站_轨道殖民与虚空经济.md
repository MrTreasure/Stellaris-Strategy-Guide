# 16｜居住站·轨道殖民与虚空经济：不占行星的「人造星球」

> 版本：4.4.6 Pegasus。居住站不是行星的替代品，而是行星之外的第三维扩张轴——它把「非行星天体」变成可殖民空间，专门解决行星不够、区划不够、好球被抢光的后期问题。配合毒圣骑士、虚空居者等起源，是 4.4 版本最高性价比的产能补充器。

## 玩法定位

居住站（Habitat）是建造在**非行星天体**（小行星、冰矮星、无行星轨道）上的人造殖民地。它的定位是：**用较小的星球面积，换取不占用行星槽位的高密度产出**。单看上限，一个满级居住站不如一颗理想城；但居住站可以**无限铺**，而且只吃「非行星天体」这个几乎不稀缺的资源，所以它是中后期产能的第二增长曲线。

- 优点：不占行星槽位、可大量堆叠、建造快、专精灵活、研究/贸易/矿业都有对口区划。
- 缺点：区划和建筑槽上限低、人口上限有限、帝国规模负担重、没有行星修饰器加成、食物区划受天体类型限制。
- 一句话：**行星负责「精」，居住站负责「量」。**

## 建造前置与获取

居住站不需要巨型工程（Mega-Engineering），前置科技走**星际基地（Voidcraft）路线**：

| 科技 | 等级 | 说明 |
|---|---|---|
| Ceramo-Metal Infrastructure | T1 | 前置之一 |
| Starhold（星际要塞） | T2 | 星际基地升级 |
| Galactic Administration（银河行政） | T2 | 前置之一 |
| **Habitats（居住站）** | **T3** | 解锁建造，需 50 影响力 + 500 合金 |

后续升级科技：

| 科技 | 效果 |
|---|---|
| 大型居住站（T3+ 随机） | 居住站区划上限 +2（4→6），解锁 T2 建筑槽 |
| 高级居住站（T4） | 区划上限再 +2（6→8），解锁 T3 建筑槽 |
| 空间建筑 | 建造相关，若需可顺路研究 |

**特别提醒（毒圣骑士）：** 毒圣骑士起源开局自带居住站科技，等于跳过整条 Voidcraft 前置链，这是该起源最大的隐藏优势之一——你不需要研究 Habitats 科技就能直接殖民居住站。别浪费这个开局红利。

**虚空居者（Void Dwellers）起源**则更极端：开局即有居住站科技 + 全帝国人口只住居住站，母星都弃用，是纯粹居住站流的核心起源。

## 区划机制（4.4.6 核心）

居住站的可用区划由**下方天体类型**决定，这是最容易踩坑的地方：

| 下方天体 | 可用区划 |
|---|---|
| 小行星带 / 岩石天体 | 矿业区划（+矿工岗位）、居住区划 |
| 冰矮星 | 农业区划（+农夫）、矿业区划 |
| 能量天体（如太阳外的能量星体） | 能源区划（+技师） |
| 任意（需建筑） | 研究区划、工业区划、贸易/娱乐区划、堡垒区划 |

**关键规则：**
- **农业区划只能建在冰矮星/海洋类天体上**——想靠居住站产食物，必须挑冰矮星。
- 矿业区划在**小行星带天体**上最多；想爆矿物，优先找小行星密集的星系铺矿业居住站。
- 研究区划 + 科研建筑是居住站的招牌玩法，一个满级研究居住站可以顶半个科研星球。
- 工业区划产合金/消费品，适合把「脏活」从理想城剥离，让理想城专心冲高百分比岗位。

## 升级与专精路线

### 单站升级顺序

1. 先建 T1 居住站（4 区划 + 8 建筑槽）。
2. 研究「大型居住站」→ 升 T2（6 区划）。
3. 研究「高级居住站」→ 升 T3（8 区划 + 全部建筑槽）。
4. 按用途塞满对应区划和建筑。

### 专精模板（4.4.6 实战向）

**研究居住站（最常用）：**
- 区划：研究区划 ×6
- 建筑：科研实验室×2、计算枢纽（+科研）、克隆中心/基因诊所（人口）、能量枢纽
- 搭配飞升「虚空行者」+ 科技至上，单站科研量级可以追平中型行星

**矿业居住站（毒圣骑士/缺矿救星）：**
- 挑**小行星带密集星系**，区划：矿业区划×6
- 建筑：矿物处理厂、能量枢纽、轨道物流（矿物吞吐）
- 配合总督 + 采矿传统，一个 T3 矿业居住站 ≈ 半颗矿业行星，且不占行星槽位

**贸易居住站：**
- 区划：贸易/娱乐区划，建筑：商业区、娱乐设施
- 适合贸易流帝国，但 4.4 贸易被削弱后优先级下降，建议只给企业帝国用

## 传统与飞升搭配

- **虚空行者（Voidborne）飞升天赋**：居住站区划 +2、产出 +25%、居住站建筑槽 +2，是居住站流的核心天赋，只要打算铺居住站就值得拿。
- **科技至上**：放大研究居住站的科研产出。
- **银河奇迹**：后期巨型结构流（物质解压器/环世界）与居住站互补，不冲突。
- **中央特权 / 权术**：减帝国规模压力，因为铺多了居住站帝国规模会涨得很快。

### 与毒圣骑士的联动（你的现状）

毒圣骑士主星被毒圣阻挡器占掉大量区划，天然缺矿。正确的解法是：

1. **开局就铺 2—3 个矿业居住站**（自带科技，零前置），用它们撑起早期矿物。
2. 矿物盈余后，把理想城做合金/消费品，居住站做矿物/科研，形成「居住站补一产 → 理想城产二产 → 骑士团吃合金」的闭环。
3. 后期巨型工程解锁后，Arc Furnace（电弧熔炉）直接取代矿业居住站成为矿物主力，矿业居住站可以转型科研或贸易。

## 与其他系统的关系

- **轨道环 vs 居住站**：轨道环建在**已殖民行星**上（增强行星），居住站建在**非行星天体**上（新殖民地）。两者不冲突，可以同时存在；但同一个天体上，轨道环和居住站**互斥**（同一槽位）。
- **栖息地 vs 环世界**：环世界是巨型结构，四段各有 50 区划，上限远超居住站；但环世界需要巨型工程 + 大师级建造者，前期根本摸不到，居住站是它之前的「穷人版」。
- **帝国规模**：每座居住站 +15 左右帝国规模（随版本微调），铺 10 个就要多开一轮行政成本，记得用权术/中央特权对冲。

## 常见误区

1. **以为居住站能产食物就随便建**——只有冰矮星能出农业区划，别在小行星带上找饭吃。
2. **把居住站当行星用，全塞人口**——居住站人口上限低，塞满不如建第二座。
3. **忽视帝国规模**——铺到 20+ 居住站却不减规模，科研会被行政成本拖垮。
4. **毒圣骑士开局不用居住站**——这是最大的浪费，自带科技等于白送一条产能线。
5. **以为需要巨型工程**——不需要！Habitats 只是 T3 Voidcraft 科技，中期就能铺。
