## 结论

这局不是实验审判没有堆起来，而是只有“科技球”形成了完整循环；“科技2”和“Ulm II”虽然有实验工程师，却没有同时吃到犯罪和杂勤加成。

实验审判的实际循环是：

`犯罪 → 星球犯罪修正 → 实验工程师/测试对象产出提高`  
`奴隶杂勤 → 进一步提高实验岗位效率`

测试对象本身不是主要倍率来源，升级实验研究所也不会按普通研究所逻辑增加大量实验工程师。

## 立即调整顺序

### 一、科技球：保持不动

科技球当前状态最好：

- 犯罪 100%
- 执法岗位为 0
- 已有 `mob_rule_experimenters` 修正
- 有 2567 个杂勤奴隶
- 有 1200 个实验工程师
- 有 2400 个测试对象

操作：

1. 不要增加执法官。
2. 不要建降低犯罪的建筑。
3. 不要安排降低犯罪的总督。
4. 如果出现犯罪领主交易，可以签约保留犯罪加成并减少后续犯罪事件。
5. 暂时不要继续升级实验研究所；除非明确需要更多测试对象并且战略资源充足。

### 二、科技2：优先补杂勤

科技2现在有 1200 实验工程师和 2400 测试对象，但杂勤为 0，是最明显的效率损失点。

操作：

1. 从其他星球迁移奴隶到科技2。
2. 在岗位面板把奴隶安排到“杂勤/奴隶杂勤”。
3. 目标先补 1000—2000 个杂勤奴隶。
4. 执法岗位保持 0。
5. 拆除或停用降低犯罪的建筑和政策。
6. 让犯罪继续上涨，至少维持在 30% 以上，最好达到 100%。
7. 稳定度保持 50 以上即可，不要为了高稳定度把犯罪压回 0。

科技2当前有 `criminal_underworld_experimenters` 修正，但没有杂勤加成，所以需要优先补奴隶，而不是继续加实验研究所等级。

### 三、Ulm II：改成第三实验星

Ulm II 当前有：

- 600 实验工程师
- 800 测试对象
- 200 个执法岗位
- 犯罪 0%
- 锻造星定位

由于首都已经承担大量合金岗位，Sol X 也在生产消费品，建议把 Ulm II 改为第三实验星。

操作：

1. 将星球定位改成科研星。
2. 把 200 个执法岗位降到 0。
3. 把奴隶迁移到 Ulm II，优先安排杂勤。
4. 保留现有实验研究所。
5. 让犯罪上涨到 30% 以上，目标 100%。
6. 稳定度跌到 50 附近时，补少量稳定度，不要重新铺满执法官。

如果不想牺牲锻造产出，就把 Ulm II 改回纯锻造星，并拆除实验建筑；不要保留“锻造星＋低犯罪实验岗位”的半成品状态。

## 实验研究所升级规则

4.4.6 中，实验研究所的升级逻辑已经改变：

- 实验工程师岗位数量基本固定。
- 建筑升级主要增加测试对象岗位。
- 测试对象的单岗位科研效率低于实验工程师。
- 升级还会增加战略资源维护压力。

所以：

- 想增加实验工程师：增加实验研究所数量。
- 想增加测试对象：升级实验研究所。
- 想提高真正的倍率：增加犯罪和杂勤奴隶。

不要把所有一级实验研究所都无脑升到最高级。

## 这局最关键的错误

你把“实验建筑数量”当成了主要倍率来源，实际上这局最缺的是：

1. 科技2的杂勤奴隶。
2. Ulm II 的犯罪修正。
3. 关闭不必要的执法岗位。
4. 不要把实验研究所升级当成实验工程师数量升级。

调整后，实验审判应当从“一颗科技球有效”变成“三颗实验星同时有效”。
