## 先统一三个术语

- **闭门**：采纳一棵普通传统树并点完五项传统，获得完成效果和一个飞升天赋槽位。
- **第一飞升槽位**：通常来自第一棵普通传统树闭门；它不等于已经完成飞升，也不代表 4.4.6 的普通人口飞升入口必然能在第 1 槽选择。普通路线与起源直入路线必须分开判断。
- **飞升路线**：选取对应飞升天赋后，还要推进局势/特殊项目并继续投入凝聚力，才能逐步完成专属传统。攻略中不再把这三个阶段统称为“第二节点”。

## 通用凝聚力预算

默认 1 倍传统花费、帝国规模不超过 100 时，按公开公式估算，完整点完第一棵树约需 **4934** 凝聚力。只靠开局被动收入却要求 2215 闭门，通常无法实现。[传统花费与帝国规模公式](https://qunxing.huijiwiki.com/wiki/传统)

| 目标 | 建议的可支配凝聚力月收入 | 解释 |
|---|---:|---|
| 2205 | 18—25 | 至少有一组专职统一岗位；不靠异常事件兜底 |
| 2210 | 25—35 | 稳健线可在 2220 前后闭门 |
| 2215 | 35—50 | 属于凝聚力冲刺，要少造研究楼、少招非必要领袖 |
| 第一飞升后 | 保留 25—40 或继续提高 | 飞升局势和后续传统仍需要凝聚力，不能闭门后全部解雇 |

以上看的是**扣除领袖、法令和特殊操作后的可支配收入**。每次殖民、扩张或征服后都重新查看传统价格；帝国规模超过 100 会提高花费。事件、考古和先驱奖励只算提前量，不写进基础时间表。

### 通用开局决策

1. 先确定玩法的飞升是否真正需要早到：依赖飞升解锁人口/舰体循环的路线冲凝聚力；依赖战争或起源局势的路线先保证合金和事件链。
2. 2200—2205 至少安排一处统一来源。普通帝国用行政/祭司等岗位，格式塔用对应协调岗位，游牧帝国在方舟上留统一区划或建筑。
3. 第一棵传统集中点完。除非某个采纳效果能立刻救经济，不要同时开三棵树。
4. 核心飞升入口到位前控制领袖招募和高额凝聚力操作；科研船不是越多越好，船和领袖必须一起算成本。
5. 闭门后再决定是继续冲飞升路线，还是把部分统一岗位转为科研、合金和舰队岗位。

## 一条通用经济原则

4.4 的人口和岗位比旧版本更容易出现“建筑造出来了，但没有人口工作”的问题。每局前十年先确定四个东西：第一颗资源殖民地、第一棵传统的凝聚力来源、飞升路线需要的科技/事件、第一场战争或防御需要的合金。不要同时铺满科研、统一、合金、贸易和特殊建筑；每次先把一个经济循环跑通，再扩张第二个循环。

### 飞升时间的读法

- 凝聚力冲刺：第一棵普通传统约 2215—2220 闭门；需要明确的统一建筑、岗位和消费品预算。
- 稳健目标：第一棵普通传统约 2220—2230 闭门；完整飞升路线通常在 2240—2260 展开。
- “最快”指有具体月产和转型方案，不是为了一个年份把所有资源岗位拆掉。
- 每新增一颗殖民地，至少同步准备基础资源、住房和维护费岗位；空球会把传统和科技一起推贵。
- 对特殊起源，先完成起源循环再飞升：虚境铸就先把进度往 0 推，游牧先建立驿道，生体荒野先生物质和活体殖民网络。
